# Source Datasets & Literature Foundations

This directory documents the external literature paradigms and conceptual source references that informed the HalluciSense 15-domain diagnostic benchmark:

### 1. HaluEval
* **Authors**: Li et al. (2023)
* **Title**: *HaluEval: A Large-Scale Hallucination Evaluation Benchmark for Large Language Models*
* **Official URL**: https://github.com/RUCAIBox/HaluEval
* **Role**: General knowledge QA and dialogue hallucination taxonomy reference.

### 2. TruthfulQA
* **Authors**: Lin et al. (2022)
* **Title**: *TruthfulQA: Measuring How Models Mimic Human Falsehoods*
* **Official URL**: https://github.com/sylagirl/TruthfulQA
* **Role**: Misconception and factuality verification patterns.

### 3. FEVER
* **Authors**: Thorne et al. (2018)
* **Title**: *FEVER: a large-scale dataset for Fact Extraction and VERification*
* **Official URL**: https://fever.ai/resources.html
* **Role**: Fact-checking and claim-evidence NLI grounding methodology.

### 4. SciFact
* **Authors**: Wadden et al. (2020)
* **Title**: *Fact or Fiction: Verifying Scientific Claims using Evidence from Research Papers*
* **Official URL**: https://github.com/allenai/scifact
* **Role**: Scientific, physics, and biomedical factuality validation principles.
