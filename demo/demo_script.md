# HalluciSense Official Demo Video Script (3-Minute / 5-Minute Demos)

## 3-Minute Executive Product Demonstration Script

### Scene 1: Problem Statement & Introduction (0:00 - 0:30)
- **Visual**: Screen capture of LLM generating a confident hallucination (e.g., medical or financial falsehood).
- **Voiceover**: "Large Language Models generate impressive text, but their hallucinations pose severe risks in medical, legal, and financial domain tasks. HalluciSense solves this by providing real-time, multi-pillar hallucination detection."

### Scene 2: Live Verification & Hybrid Inference (0:30 - 1:30)
- **Visual**: User submits query to HalluciSense React/Next.js dashboard. System highlights extracted claims, computes Pillar 1 evidence grounding, Pillar 2 self-consistency, and displays 0.04 risk score.
- **Voiceover**: "HalluciSense extracts atomic claims, searches authoritative sources like Wikipedia and PubMed, reranks evidence with CrossEncoders, and evaluates intra-model contradiction matrices."

### Scene 3: Explainability & SHAP Attributions (1:30 - 2:30)
- **Visual**: Zoom into interactive SHAP feature attributions, support DAG graphs, and calibration curves.
- **Voiceover**: "Every risk probability is fully explainable through SHAP attributions and topological support graphs."

### Scene 4: Conclusion & Quick Start (2:30 - 3:00)
- **Visual**: GitHub repository link, Docker run command, and paper citation.
- **Voiceover**: "HalluciSense v1.0 is open source. Install in under 10 minutes or deploy on Railway today."
