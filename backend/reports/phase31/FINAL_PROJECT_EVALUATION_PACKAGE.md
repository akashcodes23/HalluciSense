## 1. Executive Summary

HalluciSense is a production-grade hallucination detection engine designed to detect, quantify, and explain factual inaccuracies and ungrounded statements generated by Large Language Models (LLMs).

Unlike traditional black-box or purely heuristic detectors, HalluciSense implements a **Tri-Pillar Hybrid Architecture** combined with a **19-Feature Meta-Classifier**:
- **Pillar 1 (Factual Evidence Grounding)**: Multi-source external knowledge retrieval (Wikipedia, Wikidata, BM25, FAISS) combined with cross-encoder Natural Language Inference (`cross-encoder/nli-deberta-v3-small`), temporal anchor resolution, and negation detection.
- **Pillar 2 (Token-Level Confidence Analysis)**: Epistemic vs. aleatoric uncertainty quantification using token generation logprobs and entropy estimation.
- **Pillar 3 (Self-Consistency & Semantic Divergence)**: Stochastic sample generation and pairwise cross-claim contradiction analysis.
- **Hybrid Meta-Classifier**: A trained `HistGradientBoostingClassifier` fusing 19 extracted features into a calibrated hallucination probability score ($H \in [0, 1]$) with an optimal operating decision threshold $\tau^* = 0.54$.

## 3. The 19-Feature Schema Explained

| Index | Feature Name | Description |
|---:|---|---|
| 1 | `p1_mean_entailment` | Average NLI entailment probability across evidence passages |
| 2 | `p1_max_entailment` | Maximum support score across all retrieved evidence |
| 3 | `p1_mean_contradiction` | Average NLI contradiction probability across evidence |
| 4 | `p1_min_support_margin` | Minimum difference between entailment and contradiction scores |
| 5 | `p1_num_claims` | Count of atomic claims evaluated in Pillar 1 |
| 6 | `p2_max_pairwise_contradiction` | Maximum contradiction between repeated generation samples |
| 7 | `p2_mean_pairwise_contradiction` | Mean contradiction between repeated generation samples |
| 8 | `p2_max_pairwise_similarity` | Maximum semantic similarity across generations |
| 9 | `p2_fraction_contradictory_pairs` | Proportion of generation pairs exhibiting contradiction |
| 10 | `p2_num_claims` | Count of claims evaluated in Pillar 2 |
| 11 | `prob_p1` | Raw calibrated Pillar 1 hallucination probability |
| 12 | `prob_p2` | Raw calibrated Pillar 2 confidence risk score |
| 13 | `logit_p1` | Log-odds transformed score of Pillar 1 |
| 14 | `logit_p2` | Log-odds transformed score of Pillar 2 |
| 15 | `prob_disagreement_abs` | Absolute difference $|P_1 - P_2|$ between pillars |
| 16 | `prob_mean` | Unweighted average $\frac{P_1 + P_2}{2}$ |
| 17 | `prob_max` | Worst-case risk estimate $\max(P_1, P_2)$ |
| 18 | `prob_min` | Best-case risk estimate $\min(P_1, P_2)$ |
| 19 | `prob_ratio` | Risk ratio $\frac{P_1 + \epsilon}{P_2 + \epsilon}$ capturing cross-pillar skew |

## 4. Key Performance Indicators & Production Benchmark

- **Optimal Operating Threshold**: $\tau^* = 0.5400$.
- **Cold Request Latency**: $1.6 - 2.0\text{ s}$ (including real-time Wikipedia search and DeBERTa NLI batch scoring).
- **Cached Request Latency**: $4.2\text{ ms}$ (99.8% latency reduction).
- **Steady State Production Memory**: $\sim 915\text{ MB}$ within a $1024\text{ MB}$ memory container.
- **Concurrency Protections**: Bounded concurrency (`MAX_CONCURRENT_ANALYSES=2`) with fallback mechanisms.

## 5. Summary of Engineering Highlights for Viva Presentation

1. **Deterministic Scientific Reproducibility**: Cryptographic checksums verify that the benchmark dataset, feature schema, and model decision parameters are preserved identically.
2. **Zero-Downtime Asynchronous Startup**: Offloaded transformer warmup to background threads, decoupling HTTP server binding from model tensor allocation to ensure instant healthcheck readiness.
3. **Multi-Layer Failure Isolation**: Resilient fallback automatically handles missing external knowledge sources or corrupted local files without system crashes.
4. **Memory-Conscious Engineering**: Singleton lazy proxies, low CPU memory transformers (`accelerate`), and PyTorch thread clamping eliminate OOM hazards on resource-constrained cloud containers.
