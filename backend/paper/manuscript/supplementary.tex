\section{Deterministic Symbolic Repair Policies}
Deterministic repairs follow explicit transform rules:
\begin{itemize}
    \item \textbf{Numerical Tolerance Rule:} Replaces mismatched numbers with consensus evidence scalar values when precision drift exceeds $\pm 1\%$.
    \item \textbf{Dimensional Unit Rule:} Standardizes SI prefixes (e.g., converting kilometers to meters) based on reference entity attributes.
    \item \textbf{Negation Polarity Rule:} Inverts explicit negation particles (\texttt{not}, \texttt{never}, \texttt{cannot}) upon high-confidence contradiction detection.
\end{itemize}
