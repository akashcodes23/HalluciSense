# HalluciSense AI Ethics & Safety Policy

1. **Intended Use**: HalluciSense is designed as an automated auditing and confidence scoring layer for LLM outputs in high-stakes domains (healthcare, legal, technical QA).
2. **Human-in-the-Loop**: High hallucination risk predictions ($\ge 0.54$) should trigger human-in-the-loop verification rather than automated censorship.
3. **Transparency**: Explanations generated by HalluciSense provide claim-level evidence attribution for user auditability.
